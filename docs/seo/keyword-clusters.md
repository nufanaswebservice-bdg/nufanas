## Content Requirements per Keyword

Setiap landing page harus memiliki:
- [ ] H1 dengan keyword utama
- [ ] 2000-4000 kata konten unik
- [ ] FAQ section (5-10 pertanyaan)
- [ ] Schema markup (Service/FAQ/Breadcrumb)
- [ ] Internal links ke halaman terkait
- [ ] CTA ke WhatsApp/form kontak
- [ ] Testimonial/social proof
- [ ] Comparison table (jika relevan)
- [ ] Price range
- [ ] Local entities (area Bandung)
- [ ] Unique images/infographic
